```sh
git clone https://github.com/aamnah/dotfiles && cd dotfiles && ./install.sh
```

<CardGrid>
	<Card title="bash and zsh, kept in sync" icon="seti:shell">
		The same aliases and functions load in both shells. Use zsh on your laptop and bash on a
		server — nothing to relearn. [Shell overview →](/dotfiles/shell/overview/)
	</Card>
	<Card title="Linux and macOS" icon="laptop">
		Commands that differ between GNU (Linux) and BSD (macOS) pick the right version
		automatically — same alias name, right command behind it.
	</Card>
	<Card title="Asks first, backs up always" icon="approve-check">
		The installer asks for your login shell and locale, shows a plan, and backs up every file
		it replaces. `-y` skips the questions. [Install →](/dotfiles/start/install/)
	</Card>
	<Card title="Works on minimal systems" icon="seti:docker">
		Tested on Ubuntu, Debian, Fedora, Arch, openSUSE and Alpine. Missing tools and locales are
		installed; anything optional is skipped quietly.
	</Card>
</CardGrid>
